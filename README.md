# Background-changer
A simple background changer for windows. just import any photo and click change and you have a new background instantly!
Made in python with the help of deepseek again teaching me (I promise ill learn to code without help gng)

## Installation
Download the .exe from Releases and run it. No installation required! also, please run the command "pip install pillow". make sure python is installed! get python from https://www.python.org/     https://www.python.org/downloads/

## Features
- Import images (PNG, JPG, JPEG, BMP, GIF)
- Preview before setting
- Dark/Light mode
- Delete all data button
